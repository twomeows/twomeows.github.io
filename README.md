# TwoMeows — сайт 🐱🐱

Промо-лендинг застосунку **TwoMeows** — двомовні аудіоказки для дітей 2–7 років.

**Live:** https://vladyslav2525.github.io/twomeows-site/

## Стек

Чистий HTML + CSS + vanilla JS, без збірки. Просто відкрий `index.html` або запусти будь-який статичний сервер:

```
python -m http.server 8080
```

## Структура

```
index.html        — лендинг
privacy.html      — політика конфіденційності (заглушка)
css/style.css     — стилі (палітра в CSS-змінних угорі файлу)
js/main.js        — скрол-анімації котиків та секцій
js/i18n.js        — перемикач мов
lang/*.json       — тексти UA / SK / EN
assets/cats/      — котики-маскоти (SVG)
assets/img/       — обкладинки книг
```

## Як замінити котиків на власні малюнки 🎨

Котики — звичайні картинки в `assets/cats/`. Збережи свій малюнок під тим самим іменем (можна .png/.webp — тоді онови розширення в `index.html`):

| Файл | Де з'являється | Поза |
|---|---|---|
| `cat-peek-left.svg` | Hero, зліва | визирає і махає лапкою |
| `cat-point-right.svg` | «Як це працює», справа | показує лапкою на кроки |
| `cat-glasses-left.svg` | «Для батьків», зліва | педагог в окулярах |
| `cat-books-right.svg` | «Бібліотека», справа | визирає з-за стосу книжок |
| `cat-sleep-left.svg` | «Чому це працює», зліва | спить, z-z-z |
| `cat-duo.svg` | фінальний CTA, зверху картки | двоє котиків разом |
| `logo-cat.svg` | шапка та футер | мордочка-логотип |

Розмір появи котика регулюється в `css/style.css` (клас `.cat`, властивість `width`).
Прив'язка котика до секції — атрибути `data-cat` (на картинці) та `data-cat-section` (на секції) в `index.html`.

## Як додати/змінити тексти

Всі тексти — в `lang/ua.json`, `lang/sk.json`, `lang/en.json`. Ключ прив'язаний до елемента через `data-i18n="ключ"` в HTML. Українська також продубльована прямо в HTML (це запасний варіант і версія для пошуковиків).

## Деплой

Сайт хоститься на GitHub Pages з гілки `main` (корінь). Просто запуш зміни:

```
git add -A && git commit -m "update site" && git push
```

Через ~хвилину зміни з'являться на сайті.
