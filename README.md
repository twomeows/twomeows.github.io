# TwoMeows — сайт 🐱🐱

Промо-лендинг застосунку **TwoMeows** — двомовні аудіоказки для дітей 2–7 років.

**Live:** https://twomeows.github.io/

## Стек

Чистий HTML + CSS + vanilla JS, без збірки. Просто відкрий `index.html` або запусти будь-який статичний сервер:

```
python -m http.server 8080
```

## Структура

```
index.html        — лендинг
privacy.html      — політика конфіденційності
404.html          — сторінка «не знайдено» (шляхи абсолютні, від кореня)
css/style.css     — стилі (палітра в CSS-змінних угорі файлу)
js/main.js        — скрол-анімації котиків та секцій
js/i18n.js        — перемикач мов
lang/*.json       — тексти UA / SK / EN
assets/cats/      — котики-маскоти (SVG)
assets/img/       — обкладинки книг + og-cover.jpg (прев'ю для месенджерів)
pictures/         — оригінали малюнків котиків (не використовуються сайтом)
```

## Котики 🎨

Авторські малюнки. Оригінали лежать у `pictures/` (повні полотна 2894×1472), робочі копії з обрізаним viewBox — в `assets/cats/`:

| Файл | Де з'являється | Поза |
|---|---|---|
| `meows_hello.svg` | Hero, зліва | визирає і махає лапкою |
| `meows_left.svg` | «Як це працює», справа | показує лапкою вліво |
| `meows_cool.svg` | «Для батьків», зліва | показує клас 👍 |
| `meows_book.svg` | «Бібліотека», справа | біля стосу книжок |
| `meows_sleep.svg` | «Чому це працює», зліва | спить на подушці |
| `meows_heart.svg` | фінальний CTA, зверху картки | складає сердечко лапками |
| `meows_logo.svg` | шапка, privacy, favicon | кругле лого (мордочка + краватка), згенероване з `pictures/meows_smile.svg` |

Якщо оновлюєш малюнок: поклади новий файл у `pictures/`, потім у копії в `assets/cats/` віднови обрізаний `viewBox` (значення видно в поточних файлах у першому рядку).
Розмір кожного котика — в `css/style.css` (класи `.cat-hello`, `.cat-point`, `.cat-cool`, `.cat-book`, `.cat-sleep`).
Прив'язка котика до секції — атрибути `data-cat` (на картинці) та `data-cat-section` (на секції) в `index.html`.

## Як додати/змінити тексти

Всі тексти — в `lang/ua.json`, `lang/sk.json`, `lang/en.json`. Ключ прив'язаний до елемента через `data-i18n="ключ"` в HTML. Українська також продубльована прямо в HTML (це запасний варіант і версія для пошуковиків).

## Деплой

Сайт хоститься на GitHub Pages (репо `twomeows/twomeows.github.io`, гілка `main`, корінь).
Pages тут «легаси»-збірка — хвилини GitHub Actions вона **не** витрачає.
Пуш іде від активного акаунта `gh`, тому спершу: `gh auth switch --user twomeoows-cell`
(мітка стара, за нею акаунт `twomeows`). Далі просто запуш зміни:

```
git add -A && git commit -m "update site" && git push
```

Через ~хвилину зміни з'являться на сайті.
